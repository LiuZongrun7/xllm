# 素材清单 · 三端参考界面

> ## ⚠️ 先读这个：这批素材是"意象参考"，不是页面蓝图
>
> 用途是**订风格**——要参考里那种干净、白底、大圆角、操作按钮一眼能点的气质，
> 按钮/标签/卡片的**手感**要接近；页面怎么排、放哪些字段、信息怎么取舍，**由我们自己定**。
>
> - **风格规格请看 [`../../设计语言.md`](../../设计语言.md)**（颜色实测值、按钮 48px 胶囊、状态胶囊、间距节奏、CSS 变量）
> - 本文档是**次要参考**：页面级的信息架构对照，用于规划页面时翻一下"这一页别人怎么组织信息"
>
> 不搬运其中的商标、文案、字体、图片资产与具体配色——我们是独立实现。

## 七、素材缺口：我们要画但参考里没有的

截图覆盖不到、必须自己补设计的部分：

1. **顾客端独立登录页**——参考只有注册和"引导页"，没有单独登录表单；我们是三端统一登录入口。
2. **顾客取消订单**（FR-17 分阶段取消）——参考只在商家端 `16-异常与售后` 有"顾客申请取消"的列表行。
3. **商家标记延迟**（FR-18）——参考有"平均备餐时长""自动暂停接单"，但没有"给这一单打延迟标记"。
4. **菜品售罄对顾客端的表现**——参考的售罄入口在商家端（`13`），顾客端只有"缺货替换"。我们需要"该菜置灰 + 已售罄"。
5. **骑手位置上报动作**（FR-23）——见上一节。
6. **空状态之外的全站错误页**（404/500）——参考只有商家端的打印机离线弹窗。
7. **三端统一的配色与字型**——参考三套皮肤互相冲突，必须自定一套。
